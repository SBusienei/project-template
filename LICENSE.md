# License guidance

Choose a license deliberately before other people reuse this project:

- **MIT**: short and permissive; suitable when broad reuse is welcome.
- **Apache-2.0**: permissive with an explicit patent grant.
- **GPL-3.0**: requires distributed derivative works to remain open source.
- **No license**: others may view the public code but do not receive permission to copy, modify, or distribute it.

Use GitHub's license picker or the official license text from [choosealicense.com](https://choosealicense.com/). Replace this guidance file with the selected license as `LICENSE`; do not edit standardized license wording casually.

Confirm that datasets, model weights, fonts, images, and third-party code have compatible licenses. Document their attribution separately when required.
